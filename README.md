# ISTIC Project

ISTIC Careers is a bilingual, static prototype for internships, final-year projects and jobs for ISTIC students in Tunisia.

## Run locally

Open `dist/index.html` in a browser or serve the `dist` folder with any static web server. No build or dependency install is required.

## Try the demo

1. Open **Demo sign-in** and choose **Company demo** (`recrutement@novalabs.example`), or open a company demo profile with a fictional work email.
2. Post an opportunity from the company dashboard.
3. Open **Students** and choose **Student demo** (`etudiant@ucar.tn`), or open a student demo profile with an `@ucar.tn` address or UCAR subdomain.
4. Find the opportunity, save it or apply, and open the student dashboard to see your activity.
5. Switch back to the same company profile to see the application in **Received applications**.

Use the EN/FR control to switch languages. Demo profiles use no passwords and do not verify email ownership. Listings, bookmarks, and applications are stored in the current browser. Use fictional information. The CV field stores a filename only. Sample employers and listings are illustrative.
